# CLAUDE.md

A learning toolkit of five workflows for learning any technology with Claude Code. Each workflow is a distinct mode of learning; together they cover a full arc from planning to retention. Merge with project-specific instructions as needed.

**Tradeoff**: these workflows bias toward structure and depth over speed. For a quick factual lookup, just ask the question directly.

## The five workflows

### 1. Roadmap: plan the path

Produces a structured learning path for a technology, language, or skill: prerequisites, foundation, intermediate, advanced, and mastery phases, each with topics, practice, and resources, plus milestones, assessment criteria, common pitfalls, and community.

Use it at the start, when you want to understand the whole journey before taking the first step.

### 2. Explain: understand a concept

Explains one concept from first principles: the basic idea in plain language, the problem it solves, the core principles, concrete examples, analogies, common patterns, gotchas, and ways to practice.

Use it when a single idea is blocking you and you want it explained as if for the first time.

### 3. Practice: drill the skill

Generates a progressive set of exercises: warm-up, core practice, challenge, and real-world scenarios, each with a clear task, expected outcome, optional hints, and a worked solution.

Use it when you understand a concept and need repetition to make it automatic.

### 4. Cheatsheet: retain what you learned

Produces a concise, scannable reference for a topic: the most common operations, syntax reference, common patterns, gotchas, and quick examples.

Use it when you already know a topic and want a single page to jog memory and avoid re-learning.

### 5. Compare: choose between options

Compares technologies, tools, or approaches across consistent dimensions: overview, a difference table, pros and cons, when to use what, migration paths, and a context-aware recommendation.

Use it when you are deciding between options and want an even-handed basis for the decision.

## How they fit together

The five workflows map onto the natural arc of learning:

- Roadmap to plan the journey.
- Explain to understand each concept along the way.
- Practice to drill the concept until it is automatic.
- Cheatsheet to retain and recall what was learned.
- Compare to choose between options when the path forks.

A typical loop: start with a roadmap, then for each topic on it use explain to understand, practice to drill, and cheatsheet to retain. Reach for compare whenever a decision between tools or approaches comes up.
