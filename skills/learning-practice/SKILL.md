# Practice exercises

Create practice exercises to help the learner master a concept or skill.

## Exercise structure

1. Warm-up: easy exercises to build confidence.
2. Core practice: exercises covering the main concepts.
3. Challenge: harder problems to stretch understanding.
4. Real-world: practical, realistic scenarios.
5. Solutions: detailed solutions with explanations.

For each exercise:

- A clear description of the task
- The expected outcome or result
- Hints if needed, without giving away the answer
- A discussion of the solution and key learnings

Make exercises progressively harder. Focus on building practical skills.
