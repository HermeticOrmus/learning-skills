# Learning roadmap

Create a structured learning path for mastering a technology, language, or skill.

## Roadmap structure

### 1. Prerequisites

What you need to know before starting:

- Required knowledge
- Helpful background
- Tools to install

### 2. Foundation

Goal: understand basics and core concepts.

Topics:

- Core concept 1
- Core concept 2
- Core concept 3

Practice:

- Exercise 1
- Exercise 2
- Mini-project

Resources:

- Tutorial links
- Documentation
- Videos

### 3. Intermediate

Goal: build practical skills.

Topics:

- Intermediate concept 1
- Intermediate concept 2
- Common patterns

Practice:

- Project 1
- Project 2
- Challenges

Resources:

- Courses
- Books
- Community

### 4. Advanced

Goal: master advanced techniques.

Topics:

- Advanced concept 1
- Advanced concept 2
- Best practices

Practice:

- Real project
- Contribute to open source
- Build something meaningful

### 5. Mastery

Goal: become an expert.

Activities:

- Deep dives into internals
- Write about it (blog, tutorials)
- Teach others
- Contribute to the ecosystem

### 6. Milestones

- Built first simple app
- Completed intermediate project
- Contributed to open source
- Built a production-ready application

### 7. Assessment

How to know you are progressing:

- Skills checklist
- Projects completed
- Concepts understood

### 8. Common pitfalls

What learners struggle with:

- Challenge 1, and how to overcome it
- Challenge 2, and how to overcome it

### 9. Community and support

- Forums to join
- Chat communities
- Mentorship opportunities
- Study groups

Create a realistic, achievable roadmap with clear milestones and practical exercises. Order topics so each rests on the one before it. Use sequence and phases rather than fixed calendar weeks, since pace varies by learner.
